# 배달기사 일당 계산기

배달 라이더가 하루 운행 데이터를 입력하면 실 운행시간, 시간당 건수, 평균 단가, 순수익까지 한 번에 계산해주는 데스크톱 프로그램입니다.

퇴근 후 운행시간 · 휴식시간 · 건수 · 매출을 직접 계산해서 기록하던 걸 자동화하고 싶어서 만들었습니다.

## 기능

- 운행시간, 휴식시간, 기름값, 식비, 건수, 매출 입력 → 자동 계산
  - 실 운행시간 (운행시간 − 휴식시간)
  - 총 지출 (기름값 + 식비)
  - 시간당 건수 (소수점 첫째 자리까지)
  - 평균 단가
  - 순수익
- 계산 결과 텍스트 파일로 저장 (하루하루 기록 누적 가능)
- 계산 버튼 누르면 입력창 자동 초기화 + 첫번째 입력창으로 커서 자동 이동
- Enter 키로도 계산 실행 가능
- 잘못된 값(빈칸, 문자, 0 나누기) 입력 시 오류 안내

## 실행 방법

exe 파일 없이 소스코드로 직접 실행합니다. Python만 설치되어 있으면 바로 실행 가능합니다.

```bash
git clone https://github.com/[사용자명]/[저장소명].git
cd [저장소명]
python 파일이름.py
```

별도 라이브러리 설치가 필요 없습니다. (`tkinter`는 Python 기본 내장 라이브러리입니다.)

## 사용법

1. 운행시간, 휴식시간, 기름값, 식비, 건수, 매출을 각 입력창에 입력합니다.
2. `계산` 버튼을 누르거나 Enter 키를 누릅니다.
3. 결과가 화면에 표시됩니다.
4. 파일명을 입력하고 `.txt 저장` 버튼을 누르면 결과가 저장됩니다.
   - 저장 위치: 소스코드 파일(`.py`)과 같은 폴더 안입니다.
   - 같은 파일명으로 계속 저장하면 하루하루 기록이 누적됩니다.

## 개발 환경

- Python 3.x
- tkinter (표준 라이브러리)
